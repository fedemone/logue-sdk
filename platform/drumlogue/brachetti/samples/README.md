# Reference samples

This directory is the reference-recording input for the measure-first workflow:
`modal_extract.py` derives modal ratios and per-mode T60s from a recording, and
`refcmp.py` scores a render against one.  It is **not** build output and nothing
here is generated.

## Why it is empty

`platform/drumlogue/brachetti/.gitignore` carries a bare `*.wav`.  Its own
comment says what it was for — *"Rendered WAV output (generated by
render_presets tool)"* — but the pattern is unanchored, so it matches at every
depth, including this directory.  The reference recordings were therefore never
committed: `git log --all -- '*.wav'` finds nothing under `brachetti/`, so
there is nothing to recover from history.  `percussion-clave-like-hit-107112.mp3`
survived only because it is an `.mp3`.

Two things followed from that, and both cost real work:

- **Pass 45 tuned the Gong against prose instead of a recording.**  With no
  reference to measure, the spectral target came from two *written* references
  in the repo that contradict each other — the `k_Gong` enum comment says the
  sample "starts with 800 Hz and settles to 1680 Hz" (rising), while
  `REALISM_REVIEW.md`'s `refcmp` row records 1147 / 815 Hz (falling).  The pass
  matched the rising one and the result was rejected on hardware.
- **`refcmp.py` was broken for four passes and nobody could see it.**  The
  pass-41 GtrStr removal shifted every preset index above 25 down by one and
  left the tool pointing Ride at 32 (RidBel), RidBel at 33 (Bongo) and HHat-O
  at 27 (Conga).  It could not run at all without samples, so the breakage was
  invisible.  Fixed in the same commit as this file — it now locates renders by
  NAME, not index.

## Before you upload: this directory does not persist

Claude Code web sessions run in an ephemeral container that is reclaimed when
the session ends, and the clone is fresh each time.  So while `*.wav` stays
gitignored, **a file uploaded here is usable only for the rest of that one
session** — the next session starts from this same empty directory.  That is
exactly the loop that produced the pass-45 problem.

Pick one deliberately:

- **Track them.**  Narrow the ignore rule to its stated purpose — the rendered
  output already lives in `rendered*/` directories, which are ignored
  separately — and let `samples/*.wav` be committed.  Short percussion one-shots
  are roughly 100-400 KB each, so the whole set below is a few MB.  Reference
  recordings persist for every future session and every future pass.
- **Keep them out of git.**  Upload at the start of a session, do the
  measurement work in that session, and commit only what is derived (tuning
  numbers, doc rows, test expectations) — never the recording.

### Known discrepancies — do not "fix" silently

- **HHat-O.**  The enum attributes `TightClosedHat.wav` to preset 26 (HHat-O),
  but `refcmp.py` and `sample_map_classics.json` both pair HHat-O with
  `OpenHatBig.wav` and `TightClosedHat.wav` with HHat-C.  A *closed*-hat
  recording at 11.6 kHz as the reference for the *open* hat looks like the enum
  line is the wrong one, but HHat-O is flagged "HW-approved, do not break", so
  settle it by listening before re-tuning anything against either.
- **Gong.**  The rising/falling contradiction described above.  Whichever
  recording is uploaded, re-measure it and correct whichever of the two written
  references disagrees.
- **Provenance is not recorded anywhere.**  No source or licence is documented
  for any of these files.  Worth capturing here when they are re-uploaded,
  especially if they end up tracked in git.

## Using them

```bash
# modal ratios + per-mode T60s from a recording
python3 modal_extract.py samples/Chinese-Gong.wav
python3 modal_extract.py samples/Taiko-Hit.wav --nmodes 10

# score renders against the references (renders located by NAME, not index)
g++ -std=c++17 -O2 -I. -I.. -I../../common -I../common -DRUNTIME_COMMON_H_ \
    render_presets.cpp -o /tmp/render_presets
/tmp/render_presets /tmp/rc/
python3 refcmp.py /tmp/rc            # defaults to /tmp/rc if omitted
```
